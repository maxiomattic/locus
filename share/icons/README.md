# App icons

Each Locus app with a COSMIC counterpart uses that app's icon, copied from the COSMIC package at build time (see `locus-desktop` in `flake.nix`):

- Files: COSMIC Files
- Notes: COSMIC Edit
- Movies: COSMIC Player

Those icons are System76's, under GPL-3.0.

The SVGs here are for apps COSMIC has no counterpart for: Photos, Music, Calendar, Contacts and Messages. They are drawn in the same style: a 128 viewBox, flat shapes with rounded corners, vertical gradients, and COSMIC's navy, teal, steel blue, grey and amber.

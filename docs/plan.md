# Locus: plan

How to get from here to [intent.md](intent.md). This plan is high level and expected to change. Implementation decisions belong in the code, not here.

1. **Foundation.** One machine runs the clan server: NixOS, Urbit ID, backups and rollback. Keep whatever existing code fits the intent.
   *Done when:* a fresh machine reaches a working server through one documented procedure.
2. **Core apps.** Notes, files, and calendar/tasks as one linked whole, in a fast keyboard-driven web interface.
   *Done when:* the author uses them as their only system for these.
3. **Agents and feedback.** Agents work through the same actions as people, within permissions. "This is broken" or "I want this" becomes a change the administrator approves.
   *Done when:* real improvements to Locus routinely come in this way.
4. **The clan.** Family and friends, more than one machine, access from outside the home.
   *Done when:* other people use it regularly without needing the author's help.
5. **Clients.** Locus-managed Linux desktops, then Android.
   *Done when:* the author's own devices run Locus clients.
6. **Heavy compute.** Local AI inference and GPU work (games, 3D, video) served to thin clients.
   *Done when:* the clan's heavy work runs on the clan's own hardware.
7. **Other clans.** Any technical person can install Locus and run their own fork.
   *Done when:* a clan the author doesn't run is using it.

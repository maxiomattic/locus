# Fonts

The browser app cannot use system fonts, so it bundles them. iced's `fira-sans` feature brings Fira Sans Regular. These add the faces rendered notes need for bold, italic and code:

- FiraSans-Bold, FiraSans-Italic, FiraSans-BoldItalic (Fira Sans 4.301)
- FiraMono-Regular (Fira Mono 3.2)
